# 本地 1.14.0 路线与界面

路线入口位于地图右下角。打开面板时，左右圆形按钮一起抬到圆角面板上方；图标沿随机方向旋转 180°，收起时反向回正。位移、面板滑动和图标旋转共用一个弹簧进度。关闭面板时先滑下，动画结束才隐藏；点击左下位置按钮会提示“改动可能未保存”并继续原动作。卡片与外层容器顶部留有 6dp 间距。

## 绘制和保存

1. 移动地图，把准星移到目标位置，再点击「确认此点」。手指可以不松开；移动本身不会自动加点。
2. 继续移动、确认下一个点。已确认节点的顺序保持不变，撤销只删除最后一个点。
3. 「保存路线」可保存多条命名路线；同名覆盖会先确认。「选择路线」会显示已保存数量和列表，载入另一条路线前会提示停止当前播放。
4. 保存内容包括节点、速度和循环设置。草稿会自动保留。

## 配速和播放

配速为分钟:秒/公里。修改配速会自动计算 m/s，修改 m/s 会计算配速。例如 5:06/km = 306 秒/公里，速度约 3.268 m/s。输入未完成时允许保留文字，但不会沿用旧速度开始播放。恢复路线时速度显示四位小数，实际播放保留保存值的完整精度。

不启用循环时，到终点后保持原地。启用循环后，增加终点到起点的返程段，按同一速度走回起点，随后继续下一圈；不会瞬移。分段计算显示各段距离、预计时间和含返程的整圈时间。

载入或开始播放时，地图会一次性展示完整路线，保留四周间距；之后用户仍可自行移动地图。绿色小球读取服务的 WGS-84 位置快照后转换到地图坐标。播放、暂停和完成时仍能显示；面板可收起而不结束播放。线路和位置标记复用覆盖物，不在每次刷新时清空地图。

## UI 设置

左侧侧栏的「UI 设置」提供预测返回动效开关、返回强度、弹簧刚度和阻尼。调整条直接显示在设置页，数值实时更新。颜色预设保留原版青绿；预设色块和双色环直接显示在设置页，无选择 Dialog；色环拖动预览，页内按钮应用。色环复用了用户 Free-Smart-lamp 项目的实现。开关使用真实 MaterialSwitch，弹簧默认刚度 150、阻尼 0.6。常规设置提供 All、Debug、Info、Warn、Error 和 Silent 日志等级，默认 All；修改会即时过滤应用自身控制台和文件日志。速度、海拔及偏移编辑框使用 12dp 圆角，编辑/列表弹窗使用 28dp Material 圆角并保留原保存回调。

页面垂直滑入、向右下退出。裁剪施加于移动页面和退出快照；半径通过 Android API 在每次页面动画时读取，API 无数据时不猜固定值。永久性圆角默认关闭，开启后仅保留左上和右上；读取成功时顶部透明角露出地图，读不到时页面到位后填充黑底。独立 viewport 限制弹簧过冲范围，避免页面越过工具栏。

开发者选项、定位、悬浮窗设置使用公开系统 action。ROM 缺入口或限制启动时回到相应系统设置并提示路径；不以开发者开关的旧状态阻止打开。

应用仅保留 MainActivity，设置、UI 设置、历史和首次协议通过 Fragment/Navigation 展示。地图保留在导航页面下方，切换页面不反复创建地图；视图引用与动画监听按生命周期释放。Material 3 使用现有 Android Views，未将 Java 文件整体迁移到 Kotlin。

## 本次诊断

新 AK 同时配置到地图初始化和 Manifest 的百度 API_KEY 元数据，私有配置文件不进入 Git。

百度 LocationClient 在这台手机上持续返回 62，曾有远程进程 DNS 失败记录，但之后主进程和远程进程 DNS 都正常，错误仍存在。通过公开 Android LocationManager 对照，应用在约三秒内取得新的 network 真实位置（mock=false，精度约 20–41 米），因此不能把最终原因直接归到 VPN。

实际定位由 Kotlin SystemLocationSource 管理，使用系统现有 GPS、network 和 fused 提供者，同时直接请求 Google Play services 融合定位（21.3.0），在前台和权限允许后注册，离开前台时解除监听。只接受本次注册后的真实位置，拒绝模拟位置与乱序旧结果；真实蓝点和路线绿球分别更新。坐标由 WGS-84 转成 BD-09 后交给百度地图，城市使用单独的逆地理编码器获取，不干扰选点信息框。实机城市查询仍收到 PERMISSION_UNFINISHED，认证尚未完成；这不影响系统真实位置与路线。用户明确提交搜索时会重新查询，并显示检索不可用的实际状态，避免无规则自动重试。该检索认证问题尚未确认最终原因。

11 月 27 日下午再次定位失败时，影梭前台、定位权限和系统请求正常，但 GPS/network 无有效位置；framework fused 仅剩模拟缓存。其他地图刷新后 network 再次返回真实位置，说明仅用系统 provider 的实机验证不足以证明稳定。新增 Google 融合接口主动请求新结果、禁用初次缓存，实机收到 provider=fused、mock=false、约 14.5 米精度的位置。Google Play services 不可用时仍请求系统 provider，不将模拟缓存作为成功结果。

模拟测试提供者可能在进程死亡后残留；冷启动会清理它们。正常停止也无条件删除测试提供者，不再以“是否启用”判断是否需要清理，避免关闭系统定位期间停止模拟后，旧测试提供者继续遮蔽真实定位。

侧栏遮罩改由独立图层管理，点击菜单后解除 DrawerLayout 的触摸拦截，侧栏快照保留弹簧退出，遮罩在 400ms 内淡出，不受 DrawerLayout 内部透明度或弹簧收敛时间影响。

实机已验证：系统真实位置更新到蓝点；循环播放超过一圈仍继续，绿色球随服务快照更新；停止模拟后 GPS/network 测试提供者被删除，并重新取得约 20–35 米精度的非模拟位置。侧栏打开和设置页入场的弹簧、400ms 遮罩淡出，以及按钮同步抬升旋转均已录屏检查。手机的弹簧开关先前关闭，验证时已开启。

维护审查修复了默认地图中心被当作显式传送点、重建遗漏选择点、Binder 尚未连接就调用、停止被网络/定位/悬浮窗条件阻断、路线播放中忽略传送却提示成功的问题。新地图传送会在位置线程原子替换路线；连接期间的请求排队。模拟权限丢失或提供者失效会发布失败终态、停 tick，并释放服务与摇杆，不再显示虚假的持续播放。
