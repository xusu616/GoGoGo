# 定制版 1.13.0 路线功能

本版本在公开的 1.12.3 源码基础上增加手动路线，保留包名 `com.suku616miao.meow.miaowuwu` 和现有启动图标。

1. 打开主界面右上角的「路线」（小屏幕可在菜单中找到）。
2. 拖动地图，将中心准星移到起点。地图停稳后点击「确认此点」。
3. 移到下一个位置，再点击「确认此点」，依次构成路线。第一个确认点立即显示起点标记，后续显示线路和当前终点。拖动和点击地图只改变候选位置，不自动增加节点。
4. 点击「撤销」删除最后一个点；「保存/选择」可命名保存、新建、载入或删除路线。草稿会自动保存。
5. 确认至少两个不同位置后，输入以米/秒为单位的速度，点击「开始」。播放过程中可暂停、继续或停止。

路线按确认节点的顺序连接和移动，需要转弯时请在转弯处添加节点。它不会自动规划沿道路行走的路径。播放时锁定路线编辑和摇杆移动，避免其他操作改变当前路线的位置；到达终点后保持在终点。停止会结束模拟位置服务。

地图移动只更新候选位置，已确认的路线使用同一个 Polyline 覆盖物；增删节点时更新坐标，不清空地图或反复创建线路。地图上的 BD-09 坐标在开始播放时转换为服务使用的 WGS-84 快照，运动进度不会随之后的拖动变化。

现有 Java Activity/Service 保留 Java，新路线模型、编辑器和运动算法使用 Kotlin。`data class` 生成坐标的值比较和 Java 可调用的 getter；服务通过普通方法调用 Kotlin 播放器。路线状态与模拟坐标只由服务工作线程修改，使用经过时间计算移动距离，跨线段保留剩余距离，暂停后恢复不会计入暂停时长。

单元测试覆盖逐点确认、拖动不加点、撤销后的快照、跨节点移动、精确终点、反子午线、高纬度和输入校验。实际地图闪动还需在支持 ARM64 的设备上观察验证。
